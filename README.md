# JH-HomeMenu

🏠 **家味食光** - 定制化家庭菜单推荐应用

专为有饮食偏好（如无葱蒜）的家庭设计的菜单管理工具。

## ✨ 功能特性

- **智能推荐**：点击「今天吃啥？」随机推荐菜品
- **分类筛选**：有肉类 / 纯素类 / 我的最爱
- **食材搜索**：按食材名称快速搜索
- **偏好标记**：收藏喜欢的菜品
- **配料清单**：显示每道菜的配料（已检查无葱蒜）

## 🚀 使用方法

直接打开 `index.html` 即可使用。

## 📁 项目结构

```
JH-HomeMenu/
├── index.html   # 主页面
├── script.js    # 应用逻辑
└── style.css    # 样式
```
